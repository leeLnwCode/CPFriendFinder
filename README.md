# CP Friend Finder

## รายละเอียดโปรเจกต์

**CP Friend Finder** คือโปรเจกต์สำหรับช่วยให้นักศึกษาในคณะสามารถค้นหาและทำความรู้จักกับเพื่อนใหม่ที่มีความสนใจหรือไลฟ์สไตล์ใกล้เคียงกัน โดยเฉพาะสำหรับ **ชาว Introvert** ที่อาจรู้สึกไม่กล้าเริ่มพูดคุยหรือเข้าหาคนใหม่ ๆ

ระบบช่วยลดความยากในการหาเพื่อนด้วยการแนะนำเพื่อนที่มีความสนใจตรงกัน ทำให้สามารถเริ่มต้นทำความรู้จักกันได้ง่ายและเป็นธรรมชาติมากขึ้น
