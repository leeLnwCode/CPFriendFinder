# ประเด็นที่พบระหว่างตรวจ Backend

บันทึกนี้ใช้ติดตามเรื่องที่ต้องคุยกับเพื่อนในทีม ยังไม่ถือว่าเป็นข้อบกพร่องที่ยืนยันจากการทดสอบทั้งหมด

| รหัส | ประเด็น | รายละเอียด | สถานะ |
|---|---|---|---|
| OBS-01 | เวอร์ชัน Java | `pom.xml` ของ Backend ระบุ Java 23 แต่เครื่องทดสอบเป็น Java 21; รันผ่านเมื่อ override เป็น 21 | รอทีมตกลงเวอร์ชันกลาง |
| OBS-02 | การตรวจสอบข้อมูล | `AuthService` ตรวจข้อมูลด้วยเงื่อนไขในเมธอด แต่ใน `RegisterRequest` และ `AuthController` ที่ตรวจยังไม่มี Bean Validation / `@Valid` ตามใบงาน | รอ Backend ตรวจและปรับ |
| OBS-03 | ความครอบคลุมของ Test | ขณะนี้มีผลยืนยันเฉพาะ `contextLoads()` ยังไม่มีผลทดสอบ Register/Login จากชุดใหม่ | อยู่ระหว่างทดสอบ |

เมื่อรันชุดทดสอบใหม่แล้ว จะบันทึกผลจริงและแยกข้อบกพร่องที่ทำซ้ำได้ลงในตาราง Defect ของไฟล์ Test Case
