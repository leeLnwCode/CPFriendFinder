# บันทึกการตรวจสอบโค้ด

**วันที่:** 30 กันยายน 2569  
**ส่วนที่ตรวจ:** AuthService, AuthController และ RegisterRequest

| รหัส | หัวข้อ | ผลการตรวจสอบ | ประเภท |
|---|---|---|---|
| OBS-01 | สภาพแวดล้อมการรันทดสอบ | `pom.xml` ระบุ Java 23; ผลทดสอบบน JDK 21 ผ่านเมื่อใช้ `-Djava.version=21` | ข้อมูลสภาพแวดล้อม |
| OBS-02 | การตรวจสอบข้อมูลฝั่ง API | AuthService ตรวจข้อมูลด้วยเงื่อนไขในเมธอด; ในโค้ดที่ตรวจ `RegisterRequest` ยังไม่มี Bean Validation annotation และ `AuthController` ยังไม่มี `@Valid` | ข้อสังเกตด้านข้อกำหนด API |

**หมายเหตุ:** ข้อสังเกตในตารางไม่ใช่ผลยืนยันความผิดพลาดจาก API Test และไม่ถูกนับเป็น Defect ในชุดทดสอบนี้
